# Supplementary Figure S12. Algorithmic robustness, negative controls and external validation

**a**, Validation-fold permutation-importance ranks from random forests fitted to all 119 measurable cholesterol-metabolism genes using repeated stratified five-fold cross-validation (three repeats). Bars show each locked hub gene's median rank across 15 validation folds; the dashed line marks rank 20. Lower ranks indicate greater importance. Six of 11 locked hub genes had median rank <=20 and seven had median rank <=30. **b**, Five-fold cross-validated AUC of the locked 11-gene logistic classifier (red point) compared with null distributions from 300 random 11-gene sets drawn without replacement from the same 119-gene pathway pool and 300 ER-label permutations. Violin interiors show the distributions and horizontal lines show medians and ranges. Fold-specific standardization was used throughout. The empirical one-sided P value was calculated as `(1 + null AUCs >= observed)/(B + 1)` and equalled 0.0033 for both controls. **c**, Random-effects meta-analysis of ER-classifier AUC across four independent cohorts. Points show cohort AUCs, horizontal bars show bootstrap 95% confidence intervals, and the diamond shows the random-effects pooled estimate. AUCs were pooled on the logit scale using the DerSimonian-Laird estimator. The pooled AUC was 0.885 (95% CI 0.826-0.925), with substantial heterogeneity (I2 = 81.2%; tau2 = 0.182; Cochran Q P = 0.0012). These analyses were post hoc robustness checks and did not alter the locked 11-gene signature.

Source data: Supplementary Tables S23-S25. Random seed: 20260804.
